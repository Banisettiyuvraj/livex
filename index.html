          About Livex

          A local-first simulated live session player. Videos are opened with the browser file API and played from a local object URL — they are never uploaded, converted, or stored by this app.

          Play a YouTube link as a live session?

          Loading this video embeds Google's YouTube player. Unlike local files, that means:

          • your browser requests video from YouTube, so this mode is online;
          • Google may set cookies and see your IP address, as on youtube.com;
          • skipping cannot be enforced — YouTube's own controls stay available.

          Local files are unaffected: they never leave your device and still work fully offline.
